Changes made by SpecReader
  - The knowledge-base file is not edited. For use in the program it is embedded unchanged as a text string (the byte-order mark removed, line ends LF; no value changed).
  - SpecReader does not run the SMARTS patterns of the file. It reads the numbers by substituent name (blocks ALKANES/CH3, CH2, CH and ALKENES) and applies them to the atoms of its own molecular graph.
  - On top of these numbers SpecReader adds its own correction terms for some oxygen environments, and reads some substituents of an alkene (heteroaryl, CX3, CHX2) as the closest tabulated row.
  - The resulting 1H shift predictions are SpecReader's own and are not output of Ambit-HNMR.
